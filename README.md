# yang-mills-activation-surface

We formulate a three-dimensional extension of a deficit-contraction
mechanism established exactly for two-dimensional $SU(2)$ lattice gauge
theory. In three dimensions, real-space blocking generates an effective
action containing infinitely many gauge-invariant interactions, so the
two-dimensional character calculation does not close exactly. We formulate
a candidate polymer norm controlling the complete family of effective
activities and derive a conditional Kotecký--Preiss criterion. We also
separate the geometric contraction mechanism from the unresolved estimates
needed to control the generated effective-action remainder. The resulting
framework identifies precise sufficient conditions for a sector-wide
exponential-decay bound, but does not claim a three-dimensional continuum
mass-gap theorem.
\end{abstract}
